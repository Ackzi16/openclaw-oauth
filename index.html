Personal automation

OpenClaw Personal

A private, single-user automation tool that connects the owner's Google account to an OpenClaw server.

What it does

OpenClaw Personal uses Google APIs only when the account owner asks it to work with Gmail, Google Calendar, or Google Drive. It can read and organize account data, draft or modify content, and carry out requested actions within the permissions shown on Google's consent screen.

Who can use it

This integration is for the project owner's personal use. It is not offered as a public service and does not accept other users.

Data handling

Google account data is processed on the owner's private OpenClaw server. The integration does not sell Google user data or use it for advertising.
